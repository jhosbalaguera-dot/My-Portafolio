Mis Proyectos

Clon de Google

Este proyecto recrea la página inicial de Google empleando únicamente HTML y CSS. Su propósito fue practicar la construcción de interfaces limpias y minimalistas, cuidando la organización del código y la disposición visual de los elementos. También permitió reforzar conceptos básicos de maquetación y diseño web, como alineación, tipografía y espaciado, logrando un resultado sencillo pero funcional.

Menu de Comida

Este proyecto es una página web creada con HTML y CSS, en la que se aplican técnicas modernas de maquetación como Grid y Flexbox. El objetivo fue diseñar una interfaz limpia y responsiva, capaz de adaptarse a distintos dispositivos sin perder orden ni estética. Durante su desarrollo se trabajó en la organización del código, la disposición visual de los elementos y la jerarquía del contenido.

Block de Notas

Este proyecto es una aplicación sencilla pensada para escribir, editar y guardar texto de manera rápida. Su finalidad es ofrecer un espacio básico para tomar apuntes, organizar ideas, crear listas o escribir fragmentos de código sin distracciones. Con un diseño minimalista y funcional, refuerza la práctica de construir herramientas útiles y ligeras enfocadas en la productividad.
